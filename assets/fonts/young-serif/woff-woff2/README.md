# Young Serif WOFF/WOFF2 format

I did generate the `WOFF/WOFF2` relying on the [provided fonts]("/assets/fonts/young-serif/") by frontend mentor that came with the project, originally they were with `.ttf` format, and I convert them to `WOFF/WOFF2` using [transfonter](https://transfonter.org/) web service.
